
# 📥 How to Download and Run IAM Policy Simulator

Thank you for checking out this tool! Follow the steps below to get started.

---

## 🔽 Download the Project

### **Option 1: Download ZIP**

1. Go to the GitHub repository page
2. Click the green **Code** button
3. Select **Download ZIP**
4. Extract the ZIP file to your device

---

### **Option 2: Clone the Repository (Requires Git)**

Open your terminal and run:

```bash
git clone https://github.com/eco4x/iam-policy-simulator.git
cd iam-policy-simulator
```

---

## ▶️ Run the Tool

Make sure you have **Python 3** installed.

Run the script using:

```bash
python iam_policy_simulator.py
```

---

## ⚙️ What You Can Do

* Create and manage roles
* Assign permissions to roles (e.g., read, write, delete)
* Create users and assign them roles
* Simulate access control decisions (ALLOW / DENY)
* Save and load IAM configurations (JSON format)
